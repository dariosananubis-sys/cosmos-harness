Es un cambio de arquitectura, no un conversor mas: se factura una vez y se emite N veces.

Las bibliotecas sueltas de cada normativa quedan citadas y fuera: cubren una jurisdiccion cada una
y obligan a reimplementar la logica por cada pais.
